# Estación de Trading

Proyecto para el desarrollo de una estación de trading orientada al análisis de mercados, gestión de estrategias, monitorización de posiciones y automatización de procesos de inversión.

## Objetivos

- Análisis de mercados
- Gestión de cartera
- Backtesting de estrategias
- Automatización de operaciones
- Generación de informes y métricas
