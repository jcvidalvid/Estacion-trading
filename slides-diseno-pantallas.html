Monitoriza. Analiza. Decide.

Una PWA móvil para consultar watchlists en tiempo real y analizar gráficos técnicos. No ejecuta órdenes ni se conecta a un broker.

Patrón inspirado en la densidad y navegación de IBKR Mobile: la información de mercado aparece primero; las acciones transaccionales desaparecen.

Mobile-first

Diseño base para 360–430 px, targets táctiles de 44 px y navegación con una mano.

Oscuro por defecto

Fondo #0D1117, verde para subida, rojo para caída y azul para acciones.

Supabase

Auth para sesión, PostgreSQL para preferencias y RLS para autorización.

Una conexión

El streaming se comparte entre pantallas y se reanuda al volver al foreground.

Estados de producto

Conexión, offline y sesión

09 / 10

● En directo

Stream activo. Los precios se actualizan con el último tick disponible.

● Reconectando

Se conserva el snapshot y se reintenta con backoff exponencial.

● Sin conexión

Se permite lectura cacheada; se deshabilitan altas, bajas y cambios persistentes.

Sesión caducada

Si el refresh falla, se limpia el estado privado y se vuelve a Login.

Comportamiento móvil

  • Al pasar a background, se pausa el stream para ahorrar datos y batería.
  • Al volver a foreground, se pide snapshot y se reanuda la suscripción en menos de dos segundos.
  • Un cambio Wi‑Fi/4G no debe exigir intervención del usuario.
  • El service worker conserva la última Watchlist para consulta offline.
  • Las operaciones sobre datos del usuario se protegen con RLS en Supabase, no solo en interfaz.

Checklist final

Reglas de construcción del MVP

10 / 10
  • PWA: instalable, fullscreen, manifest, iconos y service worker.
  • Supabase: Auth para autenticación; PostgreSQL para watchlists y preferencias; RLS para autorización.
  • Streaming: una conexión compartida, snapshot + deltas, reconexión robusta.
  • Gráfico: táctil, 5m/1h/1D, indicadores básicos y rendimiento en gama media.
  • Validación: 360–430 px, iPhone/Android reales, safe areas y tamaño de fuente.
Fuera del MVP

Órdenes, paper trading, posiciones, balance, broker, opciones, alertas, noticias, nivel II, 2FA y aplicaciones nativas independientes.

Resultado esperado

Una app ligera donde el usuario abre una watchlist, encuentra un activo, entiende su cotización y llega a un gráfico táctil sin fricción.
